# 🌲 Terraria Sync

Утилита с современным графическим интерфейсом для Windows для быстрой и безопасной синхронизации сохранений Terraria (персонажей и миров) между компьютером и Android-устройством по USB через ADB.

---

## ✨ Основные возможности

- 🎮 **Двусторонняя синхронизация**:
  - `ПК ➔ Android`: перенос персонажей и миров с компьютера на телефон.
  - `Android ➔ ПК`: перенос сохранений с телефона в папку Terraria на компьютере.
- 🎨 **Современный тёмный интерфейс**:
  - Удобные карточки для настроек ПК, Android и действий синхронизации.
  - Адаптивные элементы управления с подсветкой при наведении.
- 📊 **Информативность и статистика в реальном времени**:
  - Автоматический подсчёт найденных персонажей (`.plr`) и миров (`.wld`) на ПК.
  - Статусные индикаторы подключения Android (🟢 подключен / 🟡 требует подтверждения / 🔴 не найден).
  - Индикатор выполнения (Progress Bar) с отображением процента и имени текущего копируемого файла.
- 🛡️ **Безопасность данных**:
  - **Автоматическое резервное копирование**: перед каждой синхронизацией исходные файлы и заменяемые версии сохраняются в каталоге `Backups/`.
  - **Проверка запущенной игры**: предупреждение при обнаружении активного процесса `Terraria.exe` на компьютере во избежание повреждения файлов.
  - Быстрый доступ к папке резервных копий и папке сохранений на ПК прямо из шапки программы.
- 🔍 **Умный поиск**:
  - Автопоиск `adb.exe` (в локальной папке проекта, Android SDK или системном `PATH`).
  - Автопоиск папки Terraria на ПК (поддержка `Documents`, `OneDrive`, русских и английских путей).
  - Автопоиск каталога сохранений Terraria на подключённом Android-устройстве.
- 🗂️ **Поддержка всех файлов сохранений**:
  - Персонажи: `.plr`, `.plr.bak`, `.plr.bak2` и т.д.
  - Карты: `.map`, `.map.bak` из подпапок каждого персонажа.
  - Миры: `.wld`, `.twld` и их резервные копии (`.bak`, `.bak2`).
  - Корректная обработка кириллицы в именах миров и персонажей (UTF-8).

## 🚀 Быстрый старт

1. **Запуск**:
   - Дважды кликните по файлу **`Запустить Terraria Sync.bat`**.
2. **Подготовка телефона**:
   - На телефоне откройте *«Настройки»* → *«Для разработчиков»* → включите **«Отладка по USB»**.
   - Подключите телефон USB-кабелем к компьютеру, разблокируйте экран и подтвердите запрос авторизации («Всегда разрешать с этого компьютера»).
3. **Определение папок**:
   - В блоке *«Телефон Android»* нажмите **«🔄 Обновить»**, затем **«🔍 Найти папку»**.
   - Если сохранения лежат по нестандартному пути, укажите каталог вручную (например: `/sdcard/Android/data/com.and.games505.TerrariaPaid`).
4. **Синхронизация**:
   - **Обязательно закройте Terraria** на обоих устройствах.
   - Нажмите нужную кнопку:
     - `⬆️ Отправить на телефон (ПК ➔ Android)`
     - `⬇️ Скачать на компьютер (Android ➔ ПК)`
   - Дождитесь завершения копирования. Вся история действий и созданные бэкапы отобразятся в журнале.

## 📁 Структура резервных копий

Перед любым изменением данных программа сохраняет файлы в папку:
`Backups\<ГГГГММДД_ЧЧММСС_МСС>_<Направление>\`
- `Source/` — полная копия всех файлов, которые были отправлены.
- `DestinationBefore/` — копии файлов, которые были заменены новыми версиями на целевом устройстве.

Файлы, которых не было в источнике, на целевом устройстве не удаляются.

---

## ⚠️ Важные примечания

- **Совместимость версий**: Программа копирует файлы сохранений, но не конвертирует их. Убедитесь, что версии Terraria на ПК и Android совместимы.
- **Ограничения Android**: На некоторых версиях Android (Android 11–16) и вендорных оболочках доступ ADB к `Android/data` может быть ограничен. В таком случае убедитесь, что в опциях разработчика включены расширенные пункты отладки или выполните экспорт средствами самой игры.
